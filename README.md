# Sistema de Academia - swift

Projeto final desenvolvido durente curso de Swift para aplicar conceitos de **Programação Orientada a Objetos (POO)**, simulando o funcionamento básico de uma academia.

## Objetivo

O projeto foi desenvolvido para praticar a criação e organização de classes, objetos e relacionamentos entre diferentes entidades de um sistema.

## Funcionalidades

- Cadastro e gerenciamento de alunos
- Cadastro de instrutores
- Gerenciamento de planos
- Cadastro de aulas
- Diferentes tipos de aulas
- Diferentes tipos de planos
- Organização das informações de uma academia

## Conceitos de POO utilizados

- Classes e objetos
- Encapsulamento
- Herança
- Polimorfismo
- Sobrescrita de métodos
- Enumerações
- Relacionamento entre classes
